# 固定共同核的等距压缩

2026-10-22。有限维确定性线性代数；Codex证明，后续实际概率/最小正谱阈值不在本次结论内。最终接受状态以audit、facade和run接受记录为准，不以存在源码代替验收。

对有限维复内积空间中的线性映射T，构造一个r维Euclidean空间到定义域的线性等距嵌入f，其中r=dim range T，满足

    T = (T composed f) composed f^*.

构造取K=(ker T)^perp的标准正交基；f是该基对应的等距同构再复合K的包含映射。f^*f=I，x-ff^*x属于range(f)的正交补，即ker T，所以T恢复。维数由ker正交补=range T^*及伴随秩相等给出。包括T=0、r=0，未作满秩/正维假设。

矩阵版本对任意有限行指标、n列矩阵A给出r=rank A以及固定n-by-r矩阵C，使

    C^H C=I_r,       A C C^H=A.

选择A=stacked[B;M]后，得到同一个**只依赖B,M**的C，r=rank stacked[B;M]，同时恢复B和M。对每一个矩阵Z:m-by-p（不只几乎处处、不只Gaussian）均有

    (ZB+M) C C^H=ZB+M,
    ((ZB+M) C)((ZB+M) C)^H=(ZB+M)(ZB+M)^H.

后者是完全相同维数的行Gram矩阵恒等式。一般情况下r不等于实际通用秩R=min(m,r)，也未必<=m；wide模型仍可能r>m。它不是原n列Gram矩阵等于r列Gram矩阵，更不能把带结构零的原列最小值改成正值。

这关闭了前一任务卡中“固定共同核压缩”的构造缺口。GramSpectrumTransfer.lean已有非零特征根/重数对应，可在后续复用；最小严格正值的实际定义桥、canonical正块谱合并、Gaussian投影独立/law及逆矩积分仍未完成。本次也没有宣称Z B C变成iid白噪声；BC通常仍有自己的协方差，需要另做固定分解。
