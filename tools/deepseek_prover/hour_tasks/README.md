# 一小时本地模型证明队列

本目录只有命题输入模板，所有新证明体必须来自 DeepSeek。
Codex 只选择命题、检索已证声明、提供上下文、检查和整合。
`sorry` 是输入孔，不是已证成果；这些模板不接入项目构建。

执行队列和截止时间在 `.tools/deepseek-hour/20261010/state.json` 与
`queue.json`；接受源码、实际提示词、原始回答和诊断也在同一运行目录。
每卡最多连续三次失败，之后换卡；只有新验收依赖出现才重试。
全部受阻时由本地模型提出更小子任务，Codex 审查后才能入队。
截止时终止自己启动的子进程并卸载指定模型，不影响其他程序。
