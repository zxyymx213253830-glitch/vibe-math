## P4 Adversarial Review: ActualSingularInverseEdges.lean

**1. Rank-zero coercion gap (Theorem 1).** `hB : B.rank = 0` is a `Nat` equality. The step `Submodule.finrank_eq_zero.mp hB` treats it as a module finrank statement. This works only if `B.rank` is definitionally the finrank of its range or if an implicit lemma bridges `Matrix.rank = 0` to `finrank (range B.mulVecLin) = 0`. The subsequent `LinearMap.range_eq_bot.mp` then correctly yields `B.mulVecLin = 0`. This chain is plausibly valid in mathlib but relies on an unstated definitional coincidence between `Matrix.rank` and `Module.finrank` of the range. Not a fatal gap, but the coercion deserves explicit verification rather than silent chaining.

**2. Totalized inverse at zero (Theorem 1).** After substituting `B = 0`, the integrand reduces to `(eigenvalues₀ i)⁻¹ ^ q` for arbitrary `q : ℝ`. If the `i`-th eigenvalue of `MᴴM` is zero, this is `0⁻¹ ^ q`. In Lean's totalized division, `0⁻¹ = 0`, so `0 ^ q` for `q ≤ 0` yields `0 ^ 0 = 1` or `0 ^ (negative)` which is defined as `0` in totalized real power—but mathematically this represents a divergent inverse moment. The theorem claims integrability for **all** `q : ℝ` without restriction. This is technically correct under totalization (the function becomes a constant), but it masks a genuine mathematical pathology: the "inverse moment" being integrated is not the analytic object one expects when eigenvalues vanish. The docstring acknowledges totalization, so this is a semantic fidelity concern rather than a formal gap.

**3. Dimensional mismatch risk (Theorem 2).** `B : Matrix (Fin p) (Fin n)` and `M : Matrix (Fin m) (Fin n)` are concatenated via `fromRows B M` into a `(p + m) × n` matrix. The hypothesis `hc : r - B.rank = m` forces the rank contribution of `M` beyond `ker B` to be exactly `m`. Combined with `hs` derived via `omega`, this asserts the restricted map has full row rank `m`. The arithmetic is sound given the hypotheses, but no assumption guarantees `p ≥ 0` or `n ≥ m`; these are inferred from type well-formedness (`Fin p`, `Fin m`). Acceptable in Lean, but the theorem implicitly relies on `n ≥ m` for `hs` to be satisfiable—this is not stated but enforced by the existence of `hr` and `hc`.

**4. AE congruence depends on unstated rank stability (Theorem 2).** The pointwise equality `heq` uses `gram_full_row_rank_coordinate_eq_rowMinimum` which requires `(complexSampleMatrix z * B + M).rank = m`. This is established inside the proof via `hp` and `gramSmallestValue_pos_iff_rank`. However, `hfloor` provides a uniform lower bound `δ > 0` on the smallest Gram value **for all `z`**. This is an extremely strong claim inherited from `correlated_rowGram_uniform_floor`. If that lemma's preconditions (specifically `hs`) are insufficient to guarantee almost-sure rank stability under the Gaussian measure, the AE equality fails. The review cannot inspect `correlated_rowGram_uniform_floor`'s proof body, but the logical dependency is: uniform floor → pointwise rank = m → coordinate identification. Any gap in the floor theorem propagates directly.

**5. No domination justification for integrable_congr.** The final step applies `integrable_congr` using the AE equality. This is valid: integrability is a measure-theoretic property invariant under AE-equal functions. No issue here.

**Summary.** Theorem 1's totalized inverse moment for arbitrary real powers over a zero-eigenvalue source is formally integrable but mathematically degenerate. Theorem 2's logic is internally consistent conditional on the uniform floor lemma; the critical dependency chain (uniform floor → rank stability → coordinate identification → integrability transfer) should be traced in the imported lemma's proof.
