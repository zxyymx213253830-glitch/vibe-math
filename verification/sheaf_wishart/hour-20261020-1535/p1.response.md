# Route Analysis: Uniform Negative-Log Moment Bound

## Setup & Goal

- **Given:** $X = |Z+M|^2$, arbitrary fixed scalar mean $M$, with $P(X \leq x) \leq x$ for all $x \geq 0$ (Lean-proved).
- **Target:** $Y = \max(0, -\log X)$ is integrable with $E[Y] \leq 1$.
- **Convention:** $\log 0 = 0$ (real convention), so $Y(\omega) = 0$ when $X(\omega) = 0$.

---

## Three Routes Evaluated

### Route A: Direct Layer-Cake (Recommended)

**Mechanism:**
$$E[Y] = \int_0^\infty P(Y > t)\, dt = \int_0^\infty P(\max(0,-\log X) > t)\, dt$$

For $t > 0$: $\{\max(0,-\log X) > t\} = \{-\log X > t\} = \{X < e^{-t}\}$ (note: strict vs. weak inequality matters—see pitfalls).

Apply small-ball bound: $P(X < e^{-t}) \leq e^{-t}$.

Then: $E[Y] \leq \int_0^\infty e^{-t}\, dt = 1$.

**Assumptions needed:**
1. Measurability of $Y$ (follows from measurability of $X$, continuity of $\max(0,-\log(\cdot))$ away from 0, and explicit handling at 0).
2. Small-ball bound $P(X \leq x) \leq x$ applies to the event $\{X < e^{-t}\}$ or $\{X \leq e^{-t}\}$.
3. Nonnegativity of $Y$ for layer-cake (satisfied by construction).

**Mathlib API hooks (uncertain markers):**
- `lintegral_eq_lintegral_meas_le` or `∫⁻ ω, Y ω ∂μ = ∫⁻ t in Ioi 0, μ {ω | t ≤ Y ω}` — need exact form.
- `integrable_nonneg_iff_probabilityTail` for equivalence of integrability and tail integral finiteness.
- Measurability of composition: `Measurable.comp` or specific log measurability lemmas.

---

### Route B: Fractional Inverse-Moment Domination

**Mechanism:** Use $-\log x \leq C_\alpha x^{-\alpha}$ for $x \in (0,1]$ and any $\alpha > 0$, then bound $E[X^{-\alpha}]$ via the small-ball condition.

**Verdict: Not recommended.**
- Introduces unnecessary parameter $\alpha$.
- Requires bounding $E[X^{-\alpha}]$ which itself uses layer-cake on $X^{-\alpha}$, adding a step.
- The bound $-\log x \leq x^{-\alpha}/\alpha$ (or similar) has constants that obscure the clean $C=1$ result.
- Does not simplify the argument; strictly dominated by Route A.

---

### Route C: Complex Disk Integral

**Mechanism:** Express $E[-\log|Z+M|^2]$ via Jensen's formula or disk averages over the complex plane.

**Verdict: Irrelevant here.**
- Overkill machinery for a one-dimensional real tail bound.
- Requires analytic function theory not present in this setup.
- Shannon/LP methods explicitly excluded; complex-analytic substitutes add no value when the real tail bound is already proved.

---

## Pitfall Inventory

| Pitfall | Risk | Mitigation |
|---------|------|------------|
| **$\log 0$ convention** | If Lean's `Real.log 0` is $-\infty$ rather than $0$, $Y$ becomes $+\infty$ on $\{X=0\}$. | Explicitly define $Y = \max(0, -\log X) \cdot \mathbf{1}_{X>0}$ or prove $\{X=0\}$ has measure zero (from $P(X\leq x)\leq x \Rightarrow P(X=0)=0$). Actually $P(X\leq 0)\leq 0$ forces $P(X=0)=0$, so convention choice doesn't affect expectation—but must be handled for well-definedness. |
| **Strict vs. weak inequality** | Layer-cake gives $P(Y > t)$ but small-ball gives $P(X \leq x)$. Need $\{Y > t\} \subseteq \{X \leq e^{-t}\}$. | For $t>0$: $Y>t \Leftrightarrow -\log X > t \Leftrightarrow X < e^{-t} \Rightarrow X \leq e^{-t}$. So $P(Y>t) \leq P(X \leq e^{-t}) \leq e^{-t}$. Safe direction. |
| **Scaling constant** | Small-ball is $P(X\leq x)\leq C \cdot x$ with $C=1$ proved. If reusing helper lemma with general $C$, final bound is $C$, not $1$. | Track constant explicitly. Since $C=1$ is proved, $E[Y]\leq 1$ follows. Do not leave as "some finite bound." |
| **Fubini/Tonelli** | Layer-cake identity requires Tonelli (nonneg integrand). | $Y \geq 0$ by construction. Use `lintegral` (not signed integral) + `integrable_nonneg_iff_probabilityTail`. |
| **Uniformity vs. pointwise** | Pointwise $L^1$ for each $M$ is known; goal is uniform bound independent of $M$. | The small-ball $P(X\leq x)\leq x$ is already uniform in $M$ (proved for arbitrary fixed $M$). Layer-cake preserves this uniformity automatically—no additional work needed. |
| **Measurability of $f=0$ locus** | Helper lemma stated for general measurable $f$ might implicitly assume $f>0$ a.e. | Not needed for one-sided upper tail. $Y=0$ on $\{X \geq 1\} \cup \{X=0\}$ (under convention). Only $\{0 < X < 1\}$ contributes. Verify helper lemma does not require positivity hypothesis. |
| **`probabilityTail` definition mismatch** | Existing `probabilityTail f t = μ.real {t ≤ f}` is for lower tail of $f$, but we need upper tail of $-\log X$. | Apply to $Y$ directly: `probabilityTail Y t = μ {t ≤ Y}`. Then $\{t \leq Y\} = \{t \leq -\log X\} \cap \{X>0\} \subseteq \{X \leq e^{-t}\}$. Or use complementary form. Check exact Mathlib definition orientation. |

---

## Actionable Priorities

1. **Execute Route A (layer-cake).** This is the only route needed. One page of math, direct application of the already-proved small-ball bound.

2. **Prove $P(X=0)=0$ first.** Immediate from $P(X\leq x)\leq x$ at $x=0$. This justifies ignoring the $\log 0$ convention for integrability purposes (though keep it for well-definedness of $Y$ as a measurable function).

3. **Establish the inclusion lemma:** For $t > 0$, $\{\omega : \max(0, -\log X(\omega)) > t\} \subseteq \{\omega : X(\omega) \leq e^{-t}\}$. Pure set-theoretic, no measure theory.

4. **Chain with existing `probabilityTail` / `lintegral` APIs.** Use `lintegral_eq_lintegral_meas_le` (or `meas_ge`) applied to $Y$, substitute the inclusion bound, evaluate $\int_0^\infty e^{-t} dt = 1$ via `integral_exp` or `integrableOn_exp_mul_Ioi`.

5. **Verify uniformity is free.** The bound $C=1$ in small-ball holds for arbitrary fixed $M$, so the resulting $E[Y]\leq 1$ is automatically uniform. Do not introduce $M$-dependent inverse moments.

6. **Do not pursue Routes B or C.** No additional lemmas needed beyond what's listed.

---

**Summary:** Layer-cake on $Y = \max(0,-\log X)$ with the inclusion $\{Y > t\} \subseteq \{X \leq e^{-t}\}$ and the proved bound $P(X\leq x)\leq x$ yields $E[Y]\leq \int_0^\infty e^{-t}dt = 1$ directly. Main formalization tasks are measurability of $Y$, the set inclusion for $t>0$, and chaining existing `lintegral`/`probabilityTail` lemmas. Zero-set has measure zero (free from small-ball at $x=0$), making the $\log 0$ convention irrelevant to the integral value.
