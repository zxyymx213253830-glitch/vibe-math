# P4 Semantic/Math Review: Central Bartlett Gram Determinant Product Law

## 1. Indexing and Shape Parameters (Correct)
The product law uses shapes `d + j.val + 1` for `j : Fin n`. With `d = t - s`, the shapes are `t - s + 1, ..., t`. This correctly matches the standard central complex Wishart determinant law for a `t × s` matrix (`t ≥ s`). The ascending order is mathematically equivalent to descending Bartlett shapes.

## 2. Rank-One Contribution Orientation (Correct)
Per instructions, `z` is a row of inner products with `inner` conjugate-linear in the first argument. The rank-one update `complexVectorGramRankOne` has entry `(j,k) = star(z_j) * z_k`, matching `zᴴ z` as an outer product. The reconstruction `centralBartlettGram` places `sqrt(r) * z_k` at `(0,k)` and its conjugate at `(k,0)`, consistent with `Aᴴ A` semantics where `z` represents normalized projections.

## 3. Zero Pivot and Empty Matrix Handling (Correct)
- **`u = 0`**: Total division yields `z = 0`, so `centralBartlettGram r 0 B = diag(r, B)`. Reconstruction holds pointwise via `normalizedColumnCoefficients_mul`.
- **`n = 0`**: `Fin 0` empty product gives `det = 1` (not 0), correctly handled by `Matrix.det_isEmpty` and `centralBartlettGammaProductLaw_zero = dirac 1`.
- **Singular wide residuals**: Allowed; no full-rank premise on `B` appears anywhere.

## 4. Determinant Factorization Requires `r > 0` (Correctly Handled)
`centralBartlettGram_det` requires `hr : 0 < r` because it divides by `sqrt(r)`. The transport in `GaussianBartlettDeterminantLaw` proves `r > 0` almost everywhere using `standardComplexColumnLaw_nonzero_ae`, then applies `Measure.map_congr` on that ae-set. The zero-measure locus `{r = 0}` does not affect the pushforward measure. This is valid.

## 10. Concrete Concerns Requiring Human Review

1. **Measurability coercion**: `(p.1 : ℂ)` embeds real `r` into complex. The product map `fun p => (p.1 : ℂ) * p.2` must be measurable w.r.t. the product σ-algebra on `ℝ × ℂ`. Lean accepts this via `fun_prop`, but verify the scalar multiplication measurability instance exists for mixed `ℝ × ℂ → ℂ`.

2. **`piFinSuccAbove` orientation**: In `centralBartlettGammaProductLaw_succ`, the equivalence splits off `Fin.last n`. Confirm this produces `Gamma(d+n+1) ⊗ pi(Fin n)` rather than `pi(Fin n) ⊗ Gamma(d+n+1)`, since multiplication in `ℂ` is commutative but the measure-theoretic product order matters for `map_prod_map`.

3. **Norm-square law dependency**: `standardComplexColumnLaw_norm_sq_law` uses `finrank_real_of_complex` which doubles the real dimension. For `EuclideanSpace ℂ (Fin m)`, the real dimension is `2m`, giving `Gamma(m, 1)` (shape = complex dimension). This is correct but easy to confuse with real Gaussian conventions.

**Summary**: No fatal errors detected. Indexing, shapes, zero-handling, and logical structure are sound. Three items above require human verification for measurability coercions and product-ordering conventions.
